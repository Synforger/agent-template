# 型が配る物の置き場の宣言 (= どの folder の直下に何を置いてよいか、 の真値のうち、 型が配る分)
#
# 型が配り、 派生は書かない (= `.synced-paths.txt` に載っていて、 取り込みのたびに上書きされる)。
# 派生だけの物の置き場は、 派生の `.tooling/layout.txt` に書く (= 同じ folder の行を、 そちらに足してよい)。
# 検査は 2 枚を足して読み、 同じ folder の同じ名前が両方に在れば赤にする。
# 型の名前を派生で持たない時は、 派生の file に `!<folder> : <名前>  # <理由>` と書く。
#
# 検査 = .tooling/docs-check/check-declarations.py (= 宣言に無い物は赤、 当たる実物の無い宣言も赤)
# 書式 = <folder> : <直下に置いてよい名前> ...
#   名前は 1 段ぶんの fnmatch。 `x/` = その名前の folder (= 自分の行が要る)。
#   `x/**` = その名前の folder と、 その下の全部 (= 中は宣言しない)
#   `?x`   = 機械によっては無い物 (= git が運ばない、 または派生が持たない。 無くても消し忘れに数えない)
