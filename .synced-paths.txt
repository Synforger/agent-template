# === sync 対象外の宣言 (= `!` prefix、 理由コメント必須) ===
# src/ に出荷しているが sync では降ろさない file。 init (= src/ の追跡 file を全部写す) で
# 一度だけ届き、 以降は派生の持ち物になるもの。
# 宣言漏れは `.tooling/local-ci/synced-paths-check.sh` が FAIL で検出する
# (= 「列挙も除外宣言もされていない出荷 file」 = 降ろし忘れの機械検出)。
!CLAUDE.md                          # init で CLAUDE.template.md から展開、 派生で書き換える
!vision.md                          # init で vision.template.md から展開、 派生が状態を書く
!.gitignore                         # init で .gitignore.template から展開、 派生で加筆する
!profile/profile.md                 # init で profile.template.md から展開、 派生が書く
!rules/always.md                    # 形態 D: base 出荷は § meta のみ、 派生 personal section と手動 merge
!.claude/skills/automation-machinery/SKILL.md # 機構の表は派生ごとに script 構成が違う (= base 版は雛形、 規律の節だけ共通)
!.tooling/startup/duplicates-allowlist.txt  # 登録行は派生の実 file を名指しする (= base へ運ぶと他派生に無い path が並ぶ)
!.tooling/startup/pc-labels.example.txt     # 派生は pc-labels.txt を自分で持つ、 base 版は書き方の例
!.tooling/startup/deployed-clones.example.txt # 派生は deployed-clones.txt を自分で持つ、 base 版は書き方の例

!pages/index.html                   # 階層のトップは派生がタブの一覧を書く (= 雛形としては init で一度だけ届く)
